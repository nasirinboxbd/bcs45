GitHub Pages প্রকাশনা

1. এই ফোল্ডারের index.html, thumbnail.png, favicon.svg ফাইল repository bcs45-এর root-এ আপলোড করুন।
2. Settings → Pages-এ গিয়ে main branch / root নির্বাচন করুন।
3. ওয়েবসাইট: https://nasirinboxbd.github.io/bcs45/
4. CSS inline রাখা হয়েছে এবং JavaScript index.html-এর শেষে রয়েছে; আলাদা CSS/JS ফাইল লাগবে না।
5. সামাজিক preview আপডেট হতে কিছু সময় লাগতে পারে; Messenger/WhatsApp/Telegram cache করতে পারে।

নোট: তথ্য সংরক্ষণ বাটন browser localStorage ব্যবহার করে; একই browser ও একই site-এ সংরক্ষিত তথ্য পাওয়া যাবে।
